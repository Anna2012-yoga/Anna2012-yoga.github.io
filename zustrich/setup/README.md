# Налаштування прийому заявок

Заявки з сайту потрапляють у **цю ж таблицю** і приходять **Анні в Telegram** —
так само, як було на Tilda.

Заповнити треба **один рядок** — токен бота. Решту скрипт знаходить сам.

---

## 1. Зробіть бота — 1 хвилина

У Telegram напишіть [@BotFather](https://t.me/BotFather):

```
/newbot
```

Він спитає назву (будь-яку) і юзернейм (має закінчуватись на `bot`).
У відповідь дасть **токен** виду `7123456789:AAEabc...` і посилання на бота.

## 2. Анна натискає Start

Надішліть Анні посилання на бота. Вона відкриває його, тисне **Start**
і пише будь-що.

Це єдина її дія. Без неї Telegram не дозволить боту їй писати.

## 3. Вставте код

У таблиці з лідами: **Розширення → Apps Script**
*(рос. «Расширения»)*

У вікні коду: **Ctrl+A**, **Delete**, вставте вміст [`Code.gs`](Code.gs).

Знайдіть угорі рядок і вставте токен між лапками:

```js
const TELEGRAM_TOKEN = '7123456789:AAEabc...';
```

**Ctrl+S**

## 4. Натисніть «Виконати»

Угорі вже обрана функція `setup` — просто натисніть **Виконати** *(Run / Выполнить)*.

Google один раз попросить дозвіл:
**Переглянути дозволи** → акаунт Анни → **Додатково** →
**Перейти до … (небезпечно)** → **Дозволити**

Попередження нормальне: Google так пише про всі неопубліковані скрипти.

**Має статися:** Анні в Telegram прийде «Приймач заявок налаштовано».

Якщо замість цього червона помилка — у ній написано, що саме не так.

## 5. Опублікуйте

**Розгорнути → Новий розгорток** *(Развернуть → Новое развертывание)*

- шестерня біля «Виберіть тип» → **Веб-застосунок**
- Виконувати від імені: **Я**
- Хто має доступ: **Усі** ← важливо, інакше сайт не достукається
- **Розгорнути**

Скопіюйте адресу, що закінчується на **`/exec`**.

## 6. Надішліть адресу мені

Тільки `/exec`. Токен не потрібен — він лишається у скрипті Анни.

Далі я пропишу її в сайт і перевірю справжньою заявкою.

---

### Якщо правили скрипт після публікації

Apps Script не підхоплює зміни сам:
**Розгорнути → Керувати розгортками → олівець → Версія: Нова → Розгорнути.**
Адреса `/exec` не змінюється.

### Якщо Анна змінить Telegram

Хай знову напише боту, і запустіть `setup` ще раз — chat_id оновиться.

### Старі заявки на Tilda

Поки підписка активна, вивантажте розділ **«Заявки»** — після закриття акаунта
вони зникнуть. Таблиця в Google належить Анні й залишиться.
